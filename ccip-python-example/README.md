# Chainlink CCIP Python Integration Example

Chainlink's Cross-Chain Interoperability Protocol (CCIP) is a permissionless messaging layer that lets developers send data and tokens between blockchains.  
This example shows how Python developers can integrate CCIP using web3.py.
